# HTML & CSS Programs

A collection of beginner to intermediate level projects built using **HTML5** and **CSS3**.  
This repository contains multiple UI designs, animations, layouts, and mini front-end projects created for learning and practice purposes.

# 📚 About This Repository

The purpose of this repository is to:

- Practice front-end development
- Improve HTML & CSS skills
- Build responsive UI components
- Learn animations and layouts
- Create reusable design ideas

Each project is stored in a separate folder with its own source files.

# 🚀 Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- CSS Animations
- Responsive Design

# ✨ Projects Included

- Animated Image Gallery


# 🎯 Goals

- Build strong CSS fundamentals
- Practice responsive web design
- Learn modern UI development
- Improve creativity in front-end design
